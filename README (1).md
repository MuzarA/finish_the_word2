# Finish the Word

Онлайн-игра в слова для двух и более игроков. Игра выбирает случайную букву, первый игрок называет слово на неё, следующий называет слово на последнюю букву предыдущего. Не успел за время хода: минус жизнь. Побеждает последний, у кого остались жизни.

Слова английские, от 3 букв, без повторов. Словарь встроен в страницу (около 112 тысяч слов).

## Файлы

- `index.html` сама игра.
- `config.js` адрес игрового сервера (см. ниже).
- `server.js` и `package.json` небольшой игровой сервер без внешних библиотек.

## Как играть

1. Открой игру, введи имя и нажми «Создать комнату». Ты получишь код из 4 символов.
2. Нажми «Скопировать ссылку» и отправь её другу (или назови код).
3. Друг открывает ссылку, вводит имя и нажимает «Войти». Открытые комнаты также видны в списке на главной.
4. Любой из вас нажимает «Начать игру».

## Как выложить игру на GitHub Pages

1. На github.com создай публичный репозиторий `finish-the-word`.
2. Add file, затем Upload files: загрузи все файлы из этой папки и нажми Commit changes.
3. Открой Settings, затем Pages. В разделе Source выбери Deploy from a branch, ветку `main` и папку `/ (root)`, нажми Save.
4. Через минуту-две игра будет доступна по адресу `https://ТВОЁ-ИМЯ.github.io/finish-the-word/`.

## Как запустить игровой сервер (нужен, чтобы играть из разных сетей)

Без сервера игроки соединяются напрямую, и это работает только внутри одной сети (например, в одной аудитории). Сервер соединяет игроков из любых сетей.

1. Файлы `server.js` и `package.json` должны лежать в корне репозитория.
2. Зайди на [render.com](https://render.com) и войди через GitHub.
3. Нажми New, затем Web Service, выбери репозиторий `finish-the-word`.
4. Укажи: Runtime — Node, Start Command — `node server.js`, Instance Type — Free. Нажми Create Web Service.
5. Когда сервис запустится, вверху страницы появится его адрес вида `https://finish-the-word-xxxx.onrender.com`. Открой его в браузере: должна появиться надпись «Finish the Word server is running».
6. В репозитории открой `config.js`, нажми значок карандаша и замени строку на `window.FTW_SERVER = "https://finish-the-word-xxxx.onrender.com";` (свой адрес). Нажми Commit changes.
7. Через минуту обнови игру (Ctrl+F5). Вверху на несколько секунд появится «Подключаюсь к игровому серверу».

Подойдёт и любой другой хостинг, который запускает Node.js командой `node server.js`.

Что нужно знать про бесплатный хостинг:

- Если никто не играл около 15 минут, сервер засыпает. Первое подключение после этого может занять до минуты.
- Комнаты хранятся в памяти сервера. Если сервер перезапустился, комнаты пропадают, игроки создают новые.

## Без интернета

Если открыть `finish-the-word.html` или `index.html` без доступа к сети, игра переключается в автономный режим: можно играть вдвоём на одном экране.
